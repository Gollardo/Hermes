# README screenshots

These screenshots were captured on 2026-09-09 in Chrome from an isolated Hermes
production-image instance running the pre-release build of `1.1.0`. The application version badge still reads `1.0.0`; no release version
was changed for these images.

The interface language and all demonstration names are English. The dataset was
created independently through the application API: two accounts, seven
categories, eight operations, four funds, five recurring rules and one one-off
plan. Its base currency is USD, selected during fresh setup. The amounts are
independent synthetic examples, not converted production balances. Language
selection never changes the accounting currency. No production backup was used.

- Desktop images use a `1440 × 1200` viewport, except the calendar at
  `1440 × 1400` to include all six week rows.
- `overview-mobile.jpg` uses a `390 × 844` viewport.
- Images must preserve the current monetary display contract and must never use
  real account names, balances, operations, schedules, backup contents, or other
  personal financial data.
- Replace affected screenshots when the public interface or represented product
  behavior changes materially. Do not treat design-QA artifacts as public README
  assets.
