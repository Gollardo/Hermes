# Imports

Owns bounded CSV/XLSX parsing, configurable format profiles, exact normalization,
read-only preview and durable source-row receipts. Application orchestration
posts and confirms through public Operations, Scheduling and Funds contracts.
All bank statuses remain visible; the user explicitly chooses fact dates.

See [ADR 0005](../../../../docs/decisions/0005-statement-import.md) for limits,
transaction/backup semantics and excluded financial scenarios.
